# Belarus Trip Map

Статическая мобильная карта для GitHub Pages + Supabase.

- обычный режим: `https://USERNAME.github.io/REPO/`
- режим добавления: `https://USERNAME.github.io/REPO/?edit=1`

Подключение:
1. Выполнить `supabase_setup.sql` в Supabase SQL Editor.
2. Вставить Project URL и publishable/anon key в `config.js`.
3. Загрузить все файлы в корень GitHub-репозитория.
4. Settings → Pages → Deploy from a branch → main / (root).
